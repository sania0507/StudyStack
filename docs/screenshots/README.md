# Screenshots

The root README links these files by name. Save a PNG over each one and the
README renders it — no markdown edit needed.

| File | What to capture |
|---|---|
| `dashboard.png` | The dashboard with a few domains, some tasks ticked, and the timer panel visible |
| `analytics.png` | The analytics page — weekly bars and the heatmap both visible |
| `vision.png` | A vision board with several images at different sizes and angles |
| `notes.png` | The notes page with folders on the left and a few dated notes in the timeline |
| `landing.png` | The public landing page |
| `profile.png` | The profile page with an avatar actually showing |

Tips that make a screenshot worth keeping:

- Take it at around 1440px wide, on the dark theme.
- Use realistic content: "Operating Systems", "Discrete Maths", a diary entry
  that sounds like a person wrote it. Empty states with "Test Task 1" look like
  a prototype; two done tasks look like a product.
- Crop out the browser chrome.
